# Conectado em Sergipe - versão HTML/CSS/JS

Versão estática baseada na página criada na Lovable.

## Estrutura

- `index.html`: página principal
- `assets/css/styles.css`: estilos do layout
- `assets/js/script.js`: filtros, cards e menu responsivo
- `assets/img/`: imagens e logos
- `favicon.ico`: ícone do navegador

## Como rodar

Abra o `index.html` no navegador ou use um servidor local:

```bash
python -m http.server 8000
```

Depois acesse:

```text
http://localhost:8000
```

## Ajustes rápidos

- Para alterar o WhatsApp, edite o link `https://wa.me/5579999999999` no `index.html`.
- Para alterar categorias, cidades ou anúncios, edite os arrays no arquivo `assets/js/script.js`.
