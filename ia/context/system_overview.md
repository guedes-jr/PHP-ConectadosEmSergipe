# System Overview

## Product
A lightweight local services directory with public listings and a simple admin panel.

## Goals
- Fast pages
- Easy maintenance
- Shared hosting compatibility
- Minimal dependencies
- Good SEO baseline

## Core entities
- usuarios
- categorias
- anuncios
- imagens

## Public flows
- browse categories
- search listings
- open listing details
- contact provider via WhatsApp

## Admin flows
- login
- create ad
- edit ad
- delete ad
- manage images
