## 🎯 OBJETIVO DO PROJETO

Criar um guia de serviços local com:

- listagem por categorias
- página individual de anúncios
- busca simples
- painel administrativo

---

## 🧱 STACK DEFINIDA

- PHP puro (sem frameworks)
- MySQL
- HTML + CSS + JS leve
- Hospedagem compartilhada

⚠️ NÃO alterar essa stack.

---

## 📦 MÓDULOS DO SISTEMA

### Público
- Home
- Categoria
- Anúncio
- Busca

### Admin
- Login
- Dashboard
- CRUD de anúncios

## ⚙️ FLUXO PRINCIPAL

1. Usuário acessa o site

3. Visualiza anúncios
